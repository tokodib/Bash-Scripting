# Bash Scripting

A collection of practical Bash scripting projects created to learn, practice, and improve Linux system administration and automation skills.

This repository is a personal learning project focused on writing useful Bash scripts instead of only practticing isolated commands or syntax examples.

The projects grandually increase incomplexity, starting with basic system monitorring and progressing toward automation, user menegement, log analysis, and server administration tasks.

## 🎯 Goals

The main goals of this repository are:
- Learn Bash scripting through practical projects
- Improve Linux command-line skills
- Understand Linux system administration concepts
- Automate repetitive administrative tasks
- Learn how to write reliable and maintainable shell scripts
- Practice error handling, logging, configuration, and input validation
- Improve Git and Github workflow
- Build a collection of practical projects thet can also serve as a portfolio

## 📚 Projects

### 01-System Monitor

A Bash-based system monitoring tool that collects information about:
- CPU usage
- RAM usage
- Disk usage
- Network traffic

This script generates an HTML report and can be executed automatically using `cron`

** Main topics: **

`Bash` · `Linux` · `awk` · `grep` · `/proc` · `HTML` · `cron`

## 📈 Progress

This repository is a work in progress.
The goal is not simply to finish the scripts, but to understand how and why they work, improve them over time, and gradually move from simple Bash scripts toward reliable Linux automation tools.

Progress will be tracked using checklists in the individual project README files.

## 📌 Project Philosophy
> Learn by building, inprove by debugging, and automate what can be automated.

Each project will start simple and become more advanced as new Bash and Linux concepts are learned.

The scripts are intended primarily as learning projects, but the lomg-term goal is to make useful enough to run on real Linux systems.
